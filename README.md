# إنترنت آمن، جيل واعٍ — مغامرة يقظان

برنامج تحسيسي تفاعلي (لعبة متعددة المستويات + رحلة تعليمية) لاستخدام آمن للإنترنت ومواقع التواصل الاجتماعي، موجّه للأطفال والشباب.

- `index.html`: البرنامج كاملًا (ملف واحد يعمل في أي متصفح).
- `intro.mp4`: المقدمة المرئية (اختيارية؛ إن غاب الملف يُتخطى تلقائيًا).

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع (Settings → Pages).

إعداد وتصميم: بن دوحة بوعلام
